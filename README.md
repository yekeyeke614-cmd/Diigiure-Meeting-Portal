# Diigiure Meeting Portal

بوابة استقبال ثابتة (HTML + CSS + JS بدون مكتبات)، تعمل مجانًا على GitHub Pages.

## النشر المجاني على GitHub Pages
1. أنشئ حسابًا على github.com ثم مستودعًا جديدًا (مثلًا `meeting-portal`).
2. ارفع `index.html` و`config.js` ومجلد `assets` (زر Add file ← Upload files).
3. من Settings ← Pages: اختر Branch = `main` والمجلد `/ (root)` ثم Save.
4. بعد دقيقة أو دقيقتين يظهر الرابط: `https://USERNAME.github.io/meeting-portal/`.

## تغيير رابط الاجتماع قبل كل موعد
1. افتح `config.js` على GitHub واضغط أيقونة التعديل.
2. ضع رابط الاجتماع الحقيقي (https) في `url`، والعنوان والموعد اختياريان.
3. اضغط Commit؛ يتحدّث الموقع خلال دقيقة تقريبًا.

## اجتماعات متزامنة (رابط خاص لكل اجتماع)
أضف مدخلًا جديدًا داخل `meetings` بمعرّف من أحرف إنجليزية وأرقام وشرطات، ثم أرسل: `https://USERNAME.github.io/meeting-portal/?m=schooldocs`.
كل رابط يوجّه إلى اجتماعه فقط، ولا يتأثر بتغيير الباقي. يمكنك وضع `expires` لإيقاف رابط بعد انتهاء الاجتماع.

## ربط meet.diigiure.com لاحقًا
Settings ← Pages ← Custom domain، ثم أضف سجل CNAME عند مزوّد النطاق يشير إلى `USERNAME.github.io`. لا حاجة لتعديل الكود.

## ما يعمل مباشرة وما يحتاج إعدادًا
- يعمل مباشرة: الواجهة، عربي/إنجليزي، الزر، نسخ الرابط، حالات الخطأ (غير مُعدّ، غير صالح، منتهي، رابط غير آمن)، الجوال.
- يحتاج منك: رابط اجتماع حقيقي (Google Meet أو Zoom أو Teams…) داخل `config.js`، وبريد الدعم (اختياري)، والنطاق (اختياري).

## ملاحظة أمنية مهمة
الاستضافة الثابتة لا تحمي الأسرار. ملف `config.js` عام، فروابط الاجتماعات فيه يمكن لأي شخص يعرف رابط البوابة الوصول إليها. لذلك لا توجد لوحة تحكم هنا عمدًا (لوحة بلا خادم لن تكون آمنة). لحماية الاجتماع فعّل غرفة الانتظار أو كلمة المرور في منصة الاجتماع نفسها.
إذا احتجت لاحقًا لروابط سرية أو لوحة تحكم محمية، فالحل المجاني المناسب هو Cloudflare Workers + KV (حدود مجانية سخية، يتطلب حسابًا مجانيًا وإعدادًا إضافيًا).

## ملفات الهوية
مجلد `assets/` يحتوي الشعار المضغوط (`logo.png`) والأيقونة (`favicon.png`) وفيديو التحميل (`loader.webm`). ارفع المجلد كاملًا مع الملفات الأخرى. إن لم يدعم المتصفح فيديو الشفافية يظهر مؤشر دائري بديل تلقائيًا.
